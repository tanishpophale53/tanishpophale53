## 🚀 Featured Projects

### 🖨️ Priox — Smart QR-Based Printing Platform
> *`Spring Boot` · `WebSocket` · `AWS S3` · `Razorpay` · `Python` · `Outbox Pattern`*

The printing industry still runs on manual steps — Priox fixes that. A production-grade platform where users **scan → upload → pay → print** with zero manual handoff.

```
🔍 Scan QR Code
    └──▶ 📄 Upload Document  (AWS Pre-signed URL + Multipart)
              └──▶ 💳 Pay Securely  (Razorpay + Idempotency)
                        └──▶ 🖨️  Auto Print Job Dispatched  (WebSocket + Python Vendor Agent)
                                  └──▶ ✅ ACK-based Order Confirmed
```

| Feature | How |
|---|---|
| ⚡ Sub-second order dispatch | WebSocket + Python-based vendor agent |
| 🔁 Zero order loss | Outbox pattern + retry mechanisms + polling fallback |
| ☁️ Secure document uploads | AWS pre-signed URLs + multipart upload |
| 💳 Duplicate-safe payments | Razorpay idempotency + ACK-based status tracking |
| 🤖 ~90% automation | End-to-end automated print job lifecycle |
